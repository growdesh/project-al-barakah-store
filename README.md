# আল-বারাকাহ স্টোর (Al-Barakah Store)

বাংলায় পরিচালিত **নগদ ও বাকি (Cash-Only) পাইকারি ব্যবসা ব্যবস্থাপনা সফটওয়্যার**।

## শুরু করার নিয়ম (Node.js 22+)

```bash
npm install
npm run dev
```

- ডেভেলপমেন্ট মোডে API সার্ভার চলে `http://127.0.0.1:3301` পোর্টে এবং ওয়েব ইন্টারফেস চলে `http://localhost:3300` পোর্টে।
- প্রোডাকশন বিল্ড ও চালানো:

```bash
npm run build
npm start
```

- টাইপচেক ও ভেরিফিকেশন:

```bash
npm run typecheck
npm run verify
```

- **স্টাফ (Staff):** মোবাইল `01806476653`, পাসওয়ার্ড `01806476653`

## ডেটা সংরক্ষণ

সকল তথ্য স্থানীয় JSON ফাইলে (`data/db.json`) সংরক্ষিত হয় এবং লগইন সেশন থাকে `data/sessions.json`-এ। প্রথমবার সার্ভার চালু হলে নমুনা পাইকারি ডেটা স্বয়ংক্রিয়ভাবে তৈরি হয়।
